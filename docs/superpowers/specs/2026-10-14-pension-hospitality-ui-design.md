# 펜션 예약 QnA 호텔형 UI 설계

## 목적

고객이 객실을 탐색·예약하고 QnA를 이용할 수 있는 공개 예약 화면과, 운영자가 예약·객실·FAQ 문서를 관리할 수 있는 관리자 화면을 제공한다. 힐튼 호텔 웹 경험의 고급스러운 정보 위계와 여백을 참고하되, 로고·상표·화면을 복제하지 않는 독자 디자인으로 구현한다.

## 시각 언어

- 기본색: 짙은 네이비, 아이보리 배경, 절제된 골드 포인트.
- 타이포그래피: 큰 세리프형 제목과 읽기 쉬운 산세리프 본문 조합.
- 객실 카드는 넓은 가로 이미지, 객실명·정원·1박 요금·예약 CTA를 포함한다.
- 객실 이미지는 롯데리조트 속초 공식 CDN 원본 URL을 참조하며, 출처 페이지 링크를 표시한다. 이미지 파일을 저장소에 복제하지 않는다.

## 고객 화면

`/`은 소개 히어로, 체크인/체크아웃/인원 검색 바, 추천 객실 카드, QnA 진입으로 구성한다. `/rooms/:id`는 객실 이미지·설명·정원·요금·가용성을 표시한다. `/reserve/:id`는 예약 폼과 서버가 발급한 예약번호를 표시한다. 로그인, 내 예약, 비회원 조회, QnA 화면은 기존 API 계약을 사용하며 오류는 한국어로 표시한다.

## 관리자 화면

`/admin`은 관리자 인증을 요구한다. 첫 화면은 오늘 예약 수, 확정 예약 수, 취소 수, 객실 점유율, FAQ 색인 상태를 KPI로 표시한다. 예약 목록은 상태·날짜·객실 기준 필터를 제공하고, 객실 관리는 활성화 상태와 가격을 수정할 수 있다. FAQ 문서 관리는 생성·수정·비활성화와 Qdrant 재색인 실행 상태를 제공한다.

## 구조와 접근성

React/Vite 단일 앱이 API 클라이언트와 인증 컨텍스트를 통해 백엔드에 연결된다. 모바일에서는 고객 탐색과 예약을 한 열로 재배치하며, 관리자 테이블은 카드형 요약 또는 가로 스크롤을 사용한다. 모든 입력은 label, 오류 설명, 키보드 탐색을 제공하고 텍스트·배경 대비는 WCAG AA를 충족한다.

## 검증

고객 화면에서는 객실 카드 이미지·예약 CTA·서버 예약번호·QnA 출처를 테스트한다. 관리자 화면에서는 비관리자의 차단, KPI 렌더링, FAQ 재색인 성공/실패 메시지, 모바일 레이아웃을 테스트한다.
